## History & Version Tracking

View history:
```
git log --oneline
```

Compare versions:
```
  git diff                                      #Unstaged vs. last commit
```
```
  git diff --staged                             #Staged vs. last commit
```
```
  git diff branch1..branch2                     #Compare two branches
```
```
  git diff commitA..commitB                     #Compare historical snapshots
```
