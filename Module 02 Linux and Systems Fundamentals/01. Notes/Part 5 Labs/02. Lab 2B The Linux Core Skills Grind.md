## Lab 2B: The Linux Core Skills Grind

**Goal.** Fluency. There is no shortcut for this and no clever way to teach it. You run the commands until they are muscle memory. Every task below has a one line answer; the deliverable is the command, its output, and one sentence explaining what the command actually did.

Set up the working data first:

```bash
mkdir -p ~/lab2b && cd ~/lab2b
sudo cp /var/log/dnf5.log ~/lab2b/pkg.log 2>/dev/null || sudo journalctl -u sshd --no-pager > ~/lab2b/pkg.log
sudo chown $USER:$USER ~/lab2b/pkg.log
getent passwd > users.txt
ps aux > procs.txt
```

### 2B.1 Navigation and inspection

1. Print your working directory, then move to `/etc`, then return to the previous directory in one command.
2. List everything in `/etc` including hidden entries, sorted by modification time, newest first, in long format.
3. Find the ten largest files anywhere under `/var/log`, sorted by size.
4. Show the last twenty lines of `/var/log/messages` and then follow it live. Explain what `-f` does that `less` cannot.

### 2B.2 grep

5. Every line in `users.txt` for an account whose shell is `/sbin/nologin`.
6. Count, do not list, how many such accounts exist.
7. Every line in `procs.txt` mentioning `systemd`, case insensitively, but **not** matching `systemd-journal`.
8. Every line in `/etc/ssh/sshd_config` that is not a comment and not blank. This one pattern is worth memorising; you will use it on every config file you ever read.

### 2B.3 awk

9. From `users.txt` (colon delimited), print username and UID only, for accounts with UID greater than or equal to 1000.
10. From `procs.txt`, print the top five processes by resident memory, showing PID, RSS, and command.
11. Sum the total `%MEM` column across all processes and print it with two decimal places.

### 2B.4 sed

12. Replace every occurrence of `nologin` with `NOLOGIN` in `users.txt`, printing to stdout without modifying the file.
13. Do the same, but in place, with a `.bak` backup.
14. Delete all comment lines from a copy of `/etc/ssh/sshd_config` and print the result.
15. Print only lines 10 through 20 of `users.txt`, using `sed` and nothing else.

### 2B.5 Pipelines

16. The five most common login shells on the system, with counts, most common first. This requires `cut`, `sort`, `uniq -c`, `sort -rn`, and `head`. Write it as one pipeline and explain why `sort` must come before `uniq`.
17. The number of distinct users currently running processes.

### 2B.6 Permissions

18. Create `report.txt`. Set it to `rw-r-----` using octal, then set the same thing using symbolic notation. Show `ls -l` after each.
19. Create a directory `shared/`, set `2770` on it, and explain in one sentence what the leading `2` does and why it matters for a team directory.
20. Show your current `umask`, work out from first principles what permissions a new file and a new directory will get, then create one of each and check whether you were right.
21. Find every file under `/usr/bin` with the setuid bit set. Pick one and explain why it needs it.
22. Give the user `deploy` read and write access to `report.txt` using an ACL, without changing the file's owner or group. Show the result with `getfacl` and explain what the `+` in `ls -l` now means.

### 2B.7 Users and groups

23. Create a group `webteam`.
24. Create a user `deploy` with `/bin/bash`, a home directory, and `webteam` as a supplementary group.
25. Set a password for `deploy` and force a change at first login.
26. Add `deploy` to the `wheel` group, then verify that `deploy` can use `sudo` and explain where that permission actually comes from. It is not the group name itself.
27. Lock the `deploy` account, show the effect in `/etc/shadow`, then unlock it.

### 2B.8 Packages

28. Install `nginx`, `htop`, `tmux`, and `sysstat`. Show the transaction summary.
29. Find out which package owns `/usr/sbin/ss`.
30. List every file installed by the `sysstat` package.
31. Show the history of dnf transactions and explain how you would undo the last one.

### 2B.9 Processes

32. Start `sleep 600` in the background. Show it with `jobs`, then with `ps`.
33. Send it `SIGSTOP`, confirm the state change in `ps` output, then `SIGCONT` it. Which column shows the state, and what letter appears?
34. Kill it with `SIGTERM`. Then start another and kill it with `SIGKILL`. Explain in one sentence why a well written daemon should never need `SIGKILL`.
35. Renice a running process from priority 0 to 10 and show the change. Then try to renice it back to 0 as a non root user and explain the error.

### 2B.10 Firewall

36. Show the default zone and the zone your host only interface is in.
37. Permanently open TCP 8080 and reload. Verify with `--list-all`.
38. Add a rich rule allowing port 3306 only from `192.168.56.0/24`. Show it.
39. Remove the 8080 rule. Show that it is gone from both the runtime and permanent configuration.
40. Explain the difference between a `firewall-cmd` command with `--permanent` and one without, and what `--reload` does to each.

### 2B.11 Deliverable

One markdown file, forty numbered entries, each with the command, the output, and one sentence of explanation. Explanations that restate the command in English ("this greps the file for nologin") earn nothing. Explain what the system did.
