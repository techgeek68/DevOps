## 2. Getting Help in Linux

**Fig. 7 · Where to look when you are stuck**

![Escalating help sources from a help flag to man to info to apropos](images/fig-07-help-sources.svg)

*A flag gives the quick summary, the manual page gives the full story, info goes deeper, and apropos finds the command in the first place.*

Linux includes built in tools for understanding commands and finding documentation. `man` displays the full manual page for a command, `--help` provides a quick summary of options, and `info` offers detailed GNU documentation. `apropos` searches man page descriptions by keyword, useful when the exact command name is unknown. `whatis` gives a one line description of a command, and `type` reveals how the shell interprets it.

---
### `man`: Manual Pages

>Examples:

* Shows manual for `ls` command usage and options
```bash
man ls
```
* Shows manual for `ssh` secure remote login usage
```bash
man ssh
```
* Shows manual for `firewall-cmd` firewall management usage
```bash
man firewall-cmd
```
* Navigation inside man:
  - Arrow keys or Page Up / Page Down: scroll
  - `/text`: search forward; `n` next match; `N` previous match
  - `q`: quit

---
### `--help`

Quick usage summary, faster than man:

> Examples:
* Shows help information for `ls` command options and usage
```bash
ls --help
```
* Shows help information for the `cp` command for copying files and options
```bash
cp --help
```
* Filters `ls` help output to show only lines related to sorting
```bash
ls --help | grep sort
```

---
### `info`

More detailed documentation for GNU tools:

> Examples:
* Displays detailed GNU info page for `ls` command usage and features
```bash
info ls
```
* Displays detailed GNU info page for `mv` command usage and file moving options
```bash
info mv
```
Navigation: `n` next node, `p` previous node, `u` up to parent, `q` quit.

---
### Finding Commands

`Finding Commands` refers to the ability to locate, identify, and learn about commands available on a Linux system. This is essential when the exact command name is unknown or when verifying which version of a command is being used.

`which` finds the full path of an executable, and `whereis` locates its binary, source, and man page files. `type` shows how the shell interprets a command as an alias, built-in, or external file. `apropos` searches man page descriptions by keyword, useful when the exact command name is unknown, and `whatis` displays a one line description of a command.

> Examples:

* Searches man page descriptions for commands related to the keyword 'copy'
```bash
apropos copy
```
* Shows a one line description of a command from the man database
```bash
whatis tar
```
* Displays how the shell resolves a command (alias, builtin, or file)
```bash
type ls
```
* Shows the full path of an executable found in the system PATH
```bash
which python3
```
* Shows locations of binary, source, and man page files for a command
```bash
whereis ls
```
