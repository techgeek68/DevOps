## 8. Text Editors

Every DevOps engineer needs to be able to edit files on a server directly from the terminal. GUI editors are not available on most servers. `vim` and `nano` are the two most commonly encountered editors.

---
### `vim`: The Standard Editor

`vim` (Vi IMproved) is available on virtually every Linux system. It has a learning curve, but it becomes very fast once you know the basics. It works in different **modes**, which is what trips up beginners.

---
**The three modes you need to know:**

| Mode | How to enter | What it does |
|---|---|---|
| Normal | Press `Esc` | Navigate, copy, delete |
| Insert | Press `i` | Type text |
| Command | Press `:` | Save, quit, search |

---
**Basic workflow:**

1. Open a file
```bash
vim filename.conf
```
2. Press `i` to enter Insert mode and type your changes
3. Press `Esc` to return to Normal mode
4. Type `:wq` and press Enter to save and quit

---
**Essential vim commands:**

| Command | Action |
|---|---|
| `i` | Enter Insert mode (before cursor) |
| `a` | Enter Insert mode (after cursor) |
| `Esc` | Return to Normal mode |
| `:w` | Save file |
| `:q` | Quit (fails if unsaved changes exist) |
| `:wq` or `:x` | Save and quit |
| `:q!` | Quit without saving (force quit) |
| `dd` | Delete current line |
| `yy` | Copy (yank) current line |
| `p` | Paste below current line |
| `u` | Undo |
| `Ctrl+r` | Redo |
| `/pattern` | Search forward |
| `n` | Next search match |
| `N` | Previous search match |
| `:%s/old/new/g` | Find and replace all occurrences in file |
| `gg` | Go to first line |
| `G` | Go to last line |
| `:set number` | Show line numbers |

---
>If you are ever stuck in vim, press `Esc` a few times and then type `:q!` to exit without saving.
---
---
### `nano`: The Beginner Friendly Editor

`nano` is simpler than vim. It shows keyboard shortcuts at the bottom of the screen so you never need to memorize them. It is a better starting point if you are new to terminal editors.

* Open a file in nano
  
```bash
nano filename.conf
```
---
**Essential nano shortcuts:**

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Save (Write Out) |
| `Ctrl+X` | Exit |
| `Ctrl+K` | Cut current line |
| `Ctrl+U` | Paste cut line |
| `Ctrl+W` | Search |
| `Ctrl+\` | Find and replace |
| `Ctrl+G` | Help |

---
> `nano` does not have modes. You type directly into the file as soon as it opens. The `^` symbol in nano's help means `Ctrl`.
---
---
### Which Editor to Use

Use `nano` when you need to make a quick edit and do not want to think about modes. Use `vim` when you are editing large files, doing find and replace across a file, or working on systems where nano may not be installed. In production environments, vim is almost always available even on minimal installs.
