## 4. Compression and Archiving

**Archiving** combines multiple files into a single file for easier storage and transfer. **Compression** reduces file size by encoding data more efficiently. These two operations are often combined in Linux.

`tar` is the primary archiving tool, bundling files into a single archive. Combined with compression flags, `-czf` uses gzip and `-cjf` uses bzip2. `gzip` and `bzip2` compress individual files, with bzip2 offering stronger compression. `xz` provides high compression ratios, commonly used for large file distribution. `zip` and `unzip` handle ZIP archives, widely used for cross-platform compatibility.

---
**Compression tools:**

| Tool | Compress | Keep original | Decompress |
|---|---|---|---|
| gzip | `gzip file_name` | `gzip -k file_name` | `gunzip file_name.gz` |
| bzip2 | `bzip2 file_name` | `bzip2 -k file_name` | `bunzip2 file_name.bz2` |
| xz | `xz file_name` | `xz -k file_name` | `unxz file_name.xz` |
| zip | `zip file_name.zip file_name` | (zip never deletes) | `unzip file_name.zip` |

---
>* **`gzip`** is the standard for quick, everyday compression where speed is the priority.

>* **`xz`** (using the LZMA algorithm) is the modern standard when minimizing file size is the primary goal, commonly used for software distribution and Linux kernels.
---

**Example: Compressing `linux.words`**

  * Copy the existing file from your server:
    
      `cp /usr/share/dict/linux.words .`
    
      `sudo cp /var/log/messages ~`
    
> If this file does not exist, install it `sudo dnf install words`

| Tool | Command Used | Resulting File | Expected File Size | Compression Speed |
| :--- | :--- | :--- | :--- | :--- |
| **(None)** | *Original File* | `linux.words` | 100% (~5 MB) | N/A |
| **gzip** | `gzip -k linux.words` | `linux.words.gz` | ~30% of original | Very Fast |
| **bzip2** | `bzip2 -k linux.words` | `linux.words.bz2` | ~24% of original | Moderate |
| **xz** | `xz -k linux.words` | `linux.words.xz` | ~20% of original (Smallest) | Slower |

---
**tar for archiving multiple files:**

`tar` packages files together. Add compression flags to compress at the same time.

| Flag | Meaning |
|---|---|
| `-c` | Create a new archive |
| `-x` | Extract from an archive |
| `-v` | Verbose: list files as they are processed |
| `-f` | Specify the archive filename |
| `-z` | Compress/decompress with gzip (.tar.gz) |
| `-j` | Compress/decompress with bzip2 (.tar.bz2) |
| `-J` | Compress/decompress with xz (.tar.xz) |
| `-t` | List contents without extracting |

---
**- Example:**

* Create files and a directory
```bash
touch file1 file2
```
```bash
mkdir dir1
```
* Create archive
```bash
tar -cvf backup.tar file1 file2 dir1
```
* Create a compressed archive
```bash
tar -czvf archive.tar.gz file1 dir1
```
