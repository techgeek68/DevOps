# Lab FM1.A: SDLC Mapping Exercise

---
**Objective**
 
Connect SDLC phases to a real application scenario and map DevOps tools at each phase.

---
**What You Need**
 
- Spreadsheet or document editor
- Internet access
- Approximately 45 minutes

---
**Prerequisites**
 
Read Section F.1 of this module before starting.

---
**Instructions**
 
Choose one of the following application scenarios:
 
- Student course registration portal

- Food delivery app connecting restaurants, riders, and customers

- Online library catalog with book borrowing and reservation features
